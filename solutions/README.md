# Solutions Index

This folder contains the implementation-by-exercise pack for the banking complaint resolution system project.

## Structure

- Sprint 1/ through Sprint 6/ contain the exercise pack for each sprint
- Each exercise now has a companion spec and solution document alongside the core exercise file
- gap-tracker.md captures dependencies, gaps, and improvement notes
- The solution files are intended to be reviewable, implementation-focused, and handoff-ready

## Recommended use

1. Start with the exercise spec to confirm the required outcome
2. Review the solution companion for a concrete implementation approach
3. Check the dependency chain between exercises before moving forward
4. Record gaps and missing bridge work for the final design review
