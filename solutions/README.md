# Solutions Index

This folder contains the implementation-by-exercise pack for the banking complaint resolution system project.

## Structure

- Sprint 1/ through Sprint 6/ contain the exercise pack for each sprint
- The core exercise markdown files remain the task briefs
- Only the dedicated spec exercises keep a separate specification document
- The remaining exercises have direct solution notes and implementation guidance
- gap-tracker.md captures dependencies, gaps, and improvement notes

## Recommended use

1. Open the exercise brief to confirm the task
2. Use the solution file for the concrete implementation pattern
3. Treat true spec exercises as the formal requirement definition points
4. Check the dependency chain between exercises before moving forward
