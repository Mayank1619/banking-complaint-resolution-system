# Solutions Index

This folder contains the implementation-by-exercise pack for the banking complaint resolution system project.

## Structure

- Sprint 1/ through Sprint 6/ contain solution notes for each sprint
- Each exercise has a dedicated Markdown file
- gap-tracker.md captures dependencies, gaps, and improvement notes

## Recommended use

1. Solve each exercise in isolation
2. Review the dependency chain between exercises
3. Record gaps and missing bridge work
4. Reuse the best patterns in the final system design
