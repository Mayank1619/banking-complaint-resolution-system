# Solutions folder structure

This folder is organized by sprint, not by separate weekly project.

## Rule

- Every Sprint N folder contains the solution files for that sprint.
- End-of-sprint deliverables such as Week 1 Showcase, Week 2 Release, Week 3 Release, and so on are still part of the same sprint and remain inside that sprint folder.
- They are not separate root-level sprints or separate week folders.

## Examples

- `solutions/Sprint 1/Exercise_1_5_2_Week1_Showcase_solution.md` belongs to Sprint 1.
- `solutions/Sprint 2/Exercise_2_5_2_Week2_Release_solution.md` belongs to Sprint 2.
- `solutions/Sprint 3/Exercise_3_5_2_Week3_Release_solution.md` belongs to Sprint 3.

## Why this matters

The naming refers to the week-level outcome within a sprint, but the filesystem is intentionally sprint-based so that exercises remain grouped by delivery cycle and traceability stays clear.
