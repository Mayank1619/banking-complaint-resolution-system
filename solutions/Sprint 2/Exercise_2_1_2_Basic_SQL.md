# Exercise_2_1_2_Basic_SQL

## Objective

Create a data foundation that supports reliable complaint analysis, reporting, and later API integration.

## Solution approach

1. Design the core schema and business rules for complaint records.
2. Write queries that validate quality, distributions, and operational metrics.
3. Use seed data to test typical cases and edge conditions.
4. Confirm the data layer is ready for the next service and reporting stages.
